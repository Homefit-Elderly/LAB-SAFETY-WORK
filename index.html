One-time setup needed

This app uses Firebase for real email accounts and cloud-saved progress. You need your own free Firebase project — takes about 5 minutes.
  1. Go to console.firebase.google.com → Add project (any name).
  2. In the project, go to Build → Authentication → Get started, enable the Email/Password sign-in method.
  3. Go to Build → Firestore Database → Create database (start in production mode is fine).
  4. In Firestore → Rules, paste: 
    rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}
  5. Go to Project Settings (gear icon) → scroll to "Your apps" → add a Web app → copy the firebaseConfig object.
  6. Open this file's HTML source, find const firebaseConfig = {...} near the top of the script, and paste your values in.
  7. Save, re-upload to GitHub, reload the page.
